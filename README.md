# پاسخ‌ها و یادداشت‌های آزمون فرانت‌اند

مجموعه‌ای از نمونه‌پاسخ‌ها، تمرین‌های عملی و یادداشت‌های مرور مباحث آزمون‌های داخلی شرکت، با تمرکز بر **React، TypeScript و توسعهٔ فرانت‌اند**.

هدف این مخزن، دسترسی سریع به مثال‌های هر موضوع و مرور روش پیاده‌سازی آن‌ها پیش از آزمون است.

## فهرست مباحث

| موضوع | فایل | محتوای نمونه |
| --- | --- | --- |
| نمایش لیست بزرگ | [10000rows](./10000rows) | نمایش ۱۰٬۰۰۰ آیتم با Virtualization، ارتفاع ثابت ردیف‌ها، Overscan و مدیریت اسکرول با `requestAnimationFrame` |
| دسترس‌پذیری | [accessibility.tsx](./accessibility.tsx) | HTML معنایی، برچسب ورودی‌ها، ویژگی‌های ARIA، پیام خطا و وضعیت، دیالوگ و متن جایگزین تصاویر |
| انیمیشن | [animation.tsx](./animation.tsx) | افزودن و حذف آیتم‌ها با انیمیشن CSS و حذف نهایی پس از `onAnimationEnd` |
| درخواست‌های HTTP | [axios.tsx](./axios.tsx) | دریافت و افزودن محصول، وضعیت بارگذاری، دسته‌بندی خطاها، Interceptor و لغو درخواست با `AbortController` |
| مدیریت خطای کامپوننت | [boundary](./boundary) | نمونهٔ Error Boundary و نمایش رابط جایگزین هنگام خطا |
| نمودار | [chart.tsx](./chart.tsx) | نمودار میله‌ای با Recharts، محور‌ها، راهنما و Tooltip |
| سیاست امنیت محتوا | [csp.md](./csp.md) | مرور CSP، دستورهای اصلی، نمونهٔ سیاست‌های توسعه و انتشار و ورودی‌های آزمایشی |
| چندزبانه‌سازی | [i18n.tsx](./i18n.tsx) | ترجمهٔ فارسی و انگلیسی، تغییر زبان، ذخیرهٔ انتخاب در `localStorage` و تنظیم `dir` و `lang` |
| برنامهٔ وب پیش‌رونده | [pwa](./pwa) | تنظیمات `vite-plugin-pwa`، Manifest، به‌روزرسانی خودکار و کش با راهبردهای `CacheFirst` و `NetworkFirst` |
| تست کامپوننت | [rtl.tsx](./rtl.tsx) | یادداشت‌های راه‌اندازی Vitest و React Testing Library، تست فرم، Mock و تعامل کاربر |
| تنظیمات Build | [vite.config.ts](./vite.config.ts) | تنظیم Alias، تقسیم خروجی به Chunkها، Tree Shaking و تحلیل اندازهٔ Bundle |
| بررسی XSS | [xss](./xss) | مقایسهٔ نمایش متن، رندر HTML خام و پاک‌سازی ورودی با DOMPurify |

> در نام فایل `rtl.tsx`، منظور از RTL کتابخانهٔ **React Testing Library** است. نمونهٔ تغییر جهت راست‌به‌چپ در `i18n.tsx` قرار دارد.

## نحوهٔ استفاده

برای مطالعه، کافی است فایل موضوع موردنظر را از جدول بالا باز کنید. برای آزمایش عملی، نمونه را در یک پروژهٔ React + TypeScript قرار دهید و وابستگی‌های همان نمونه را نصب کنید.

این مخزن مجموعه‌ای از فایل‌های مستقل است؛ در وضعیت فعلی `package.json`، نقطهٔ ورود برنامه و ساختار کامل پروژه ندارد، بنابراین اجرای مستقیم آن با `npm run dev` امکان‌پذیر نیست.

### وابستگی‌های نمونه‌ها

علاوه بر React و TypeScript در پروژهٔ میزبان، هر نمونه ممکن است به بسته‌های زیر نیاز داشته باشد:

| نمونه | بسته‌های مرتبط |
| --- | --- |
| `animation.tsx` | `classnames` |
| `axios.tsx` | `axios` |
| `chart.tsx` | `recharts` |
| `i18n.tsx` | `i18next`، `react-i18next` |
| `xss` | `dompurify` |
| `rtl.tsx` | `vitest`، `jsdom`، `@testing-library/react`، `@testing-library/jest-dom`، `@testing-library/user-event` |
| `vite.config.ts` | `vite`، `@vitejs/plugin-react-swc`، `rollup-plugin-visualizer` |
| `pwa` | `vite`، `@vitejs/plugin-react-swc`، `vite-plugin-pwa`، `vitest` برای تنظیمات تست موجود در نمونه |

### آماده‌سازی فایل‌ها برای اجرا

- فایل‌های `10000rows` و `xss` را با پسوند `.tsx` در پروژهٔ میزبان قرار دهید.
- نمونهٔ `boundary` به Import کردن React نیاز دارد؛ برای استفاده در TypeScript، نوع Props و State را نیز تعریف کنید.
- فایل `rtl.tsx` شامل دستور نصب، تنظیمات و نمونهٔ تست است. هر بخش را در فایل مربوط به خودش قرار دهید و کامپوننت `Login` را مطابق سناریوهای تست پیاده‌سازی کنید.
- برای `animation.tsx`، فایل `animation.module.css` را از CSS کامنت‌شدهٔ انتهای نمونه بسازید.
- برای نمونهٔ `pwa`، آیکون‌ها، فایل‌های Asset و فایل راه‌اندازی تست ارجاع‌شده را در پروژهٔ میزبان فراهم کنید.
- تنظیمات `pwa` و `vite.config.ts` دو نمونهٔ جدا هستند؛ بخش‌های موردنیاز را با تنظیمات پروژهٔ خود ادغام کنید.
- نسخهٔ بسته‌ها را با APIهای استفاده‌شده هماهنگ کنید؛ از جمله `useEffectEvent` در نمونهٔ چندزبانه‌سازی و ویژگی `responsive` در نمونهٔ نمودار.

## روش پیشنهادی مرور

1. فایل موضوع را بخوانید و مسئله‌ای را که حل می‌کند مشخص کنید.
2. نمونه را در پروژهٔ تمرینی اجرا کنید و رفتار آن را بررسی کنید.
3. بدون نگاه‌کردن به پاسخ، همان سناریو را دوباره پیاده‌سازی کنید.
4. حالت‌های خطا، ورودی خالی و رفتارهای مرزی را متناسب با موضوع بررسی کنید.

## تکمیل مجموعه

برای اضافه‌کردن پاسخ جدید، یک فایل با نام مرتبط با موضوع ایجاد کنید و توضیح کوتاهی از مسئله، روش حل و وابستگی‌های لازم در آن بنویسید. سپس لینک آن را به جدول مباحث اضافه کنید.

این مثال‌ها برای تمرین و مرور گردآوری شده‌اند و بعضی از آن‌ها به تکمیل نیاز دارند. بخش رندر HTML خام در فایل `xss` نیز عمداً ناامن است و صرفاً برای مقایسهٔ آموزشی قرار دارد.
